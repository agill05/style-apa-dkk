# CARA MEMASANG CITATION STYLE "dkk" PADA MENDELEY DEKSTOP
1. download file "apa-dkk.csl"
2. copy/pindahkan file "apa-dkk.csl" kemudian pindahkan ke "C:\Users\NAMA_ANDA\AppData\Local\Mendeley Ltd\Mendeley Desktop\FOLDER_BERISI_FILE_.CSL"
3. nama subfolder bisa beda per versi, jadi cari folder yang berisi file ".csl"
4. kemudian buka Mendeley Dekstop, lalu pilih "View"  kemudian pilih "Citation Style" terakhir pilih "APA 7th dkk"
5. lalu cobalah kembali melakukan cite pada Word anda, dan jangan lupa pada referensi style Mendeley pada word pilih sesuai dengan yang ada pada Mendeley Dekstop yaitu "APA 7th dkk"
6. berhasil melakukan perubahan cite dari et-al menjadi dkk. jika tidak berhasil, cobalah uninstall plugin MS Word pada Mendeley Dekstop kemudian install kembali.
